## 6. Security findings and blockers

1. **Critical — repository privacy:** repository visibility remains public, not private.
2. **Critical — branch governance:** main is unprotected and required status-check enforcement is off.
3. **High — identity and tenant isolation:** Managed Better Auth is provisioned only on staging and is not integrated into the app; production has no `neon_auth` schema, workspace membership or user ownership.
4. **High — database authorization:** RLS is disabled on both A1 application tables in production and staging; no policies exist. Company A/B isolation is unproven.
5. **High — hosting:** no A1 Vercel project, production runtime or live smoke test is verified.
6. **Medium — shared abuse controls:** PR #46 addresses unbounded in-memory key growth only. The limiter is still process-local, and the client-address trust chain has not been verified against a live production host. It is not a distributed quota or a production abuse boundary.
7. **Not tested:** authenticated end-to-end flows, cross-tenant SELECT/INSERT/UPDATE/DELETE, durable memory governance, connector isolation, ERP2 contract tests, POS/accounting integrity, production backup restore and live deployment smoke tests.
