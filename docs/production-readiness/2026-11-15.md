## Remaining release blockers

1. **Identity and ownership:** no verified authentication, user identity, organization membership, or role enforcement. Chat sessions still rely on a client-provided UUID without verified ownership.
2. **Tenant isolation:** no organization/tenant key or RLS policy exists. Cross-business reads/writes cannot yet be proven safe.
3. **Database lifecycle:** both Neon branches are archived; restore point/backup and recovery procedures are not verified. No production migration was applied.
4. **Hosting:** no linked Next.js-compatible production deployment or verified server environment contract.
5. **Operational controls:** shared distributed rate limiting, spend quotas, audit logging, abuse controls, observability, privacy/retention/export/deletion remain incomplete or unverified.
6. **Business capabilities:** Seller CRM/catalogue/inventory/orders, POS/accounting, property brokerage, marketing research/campaign analytics, and customer-support workflows are not implemented as verified end-to-end product modules.
7. **Test coverage:** calculator unit tests now run in CI, but authentication, tenant/RLS, API integration, Playwright E2E, POS/accounting integrity, and post-deploy smoke tests remain absent.
