## Remaining release blockers

1. **Repository controls:** visibility is public and main-branch protection is disabled.
2. **Authentication integration:** Managed Better Auth exists on staging, but the Next.js SDK, sign-up/sign-in UI, session verification in API routes, cookie configuration, and end-to-end auth tests are not yet integrated.
3. **Tenant isolation:** application tables have no user/workspace ownership columns or RLS policies. Cross-tenant isolation is not proven.
4. **Database authorization model:** decide and test a secure server-side database access path. Do not assume owner-role SQL queries are constrained by RLS; the current server-side Neon connection must not be treated as tenant-isolated.
5. **Production database lifecycle:** snapshot and staging branch exist, but a tested restore procedure and production migration plan are not complete.
6. **Hosting:** no verified Next.js-compatible deployment, environment-variable setup, trusted origin, or live health/smoke test.
7. **Operations:** shared distributed rate limiting, spend quotas, audit logging, abuse controls, observability, privacy/retention/export/deletion remain incomplete or unverified.
8. **Business capabilities:** Seller/Admin CRM, catalogue, inventory, orders, POS/accounting, property brokerage, marketing research/campaign analytics, and customer support are not implemented as verified end-to-end workflows.
9. **Testing:** request-body tests are added, but auth, workspace membership, RLS, cross-tenant negative tests, API integration, Playwright E2E, accounting integrity, and post-deploy smoke tests remain absent.

## Release decision

**A1 remains NOT PRODUCTION READY.** Request-body memory-exhaustion protection is merged and verified. A staging Neon Auth environment and pre-auth snapshot now exist, but authentication is not integrated into the application, RLS and tenant isolation are still absent, and no production deployment is verified. Do not store confidential customer, sales, property, POS, or accounting data in A1 until these blockers are resolved.
