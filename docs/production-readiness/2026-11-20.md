## 6. Security findings and release blockers

1. **Critical — repository privacy/governance:** repository is public although private visibility is required; `main` is unprotected and required-status enforcement is off.
2. **Critical/High — identity and tenant isolation:** production app has no verified account authentication, workspace membership, ownership checks or RLS. Cross-tenant A/B isolation is unproven.
3. **High — production hosting:** no linked Vercel project/deployment was found; production API availability, environment configuration and live smoke tests are unverified.
4. **High — Managed Better Auth is staging-only:** provider tables/config exist on staging, but app SDK, auth API route, sign-in/sign-up UI and API route protection are absent. Trusted origins are empty.
5. **Medium — rate limiting:** main still uses unbounded process-local maps. PR #46 bounds memory but remains per-instance; it is not a distributed quota. The forwarded-address trust chain has not been validated against a live host.
6. **High — database recovery:** no automatic production snapshot schedule and no tested restore drill were verified.
7. **Not tested:** auth E2E, revoked-session behavior in the app, cross-tenant SELECT/INSERT/UPDATE/DELETE, search/cache/job/AI-context isolation, accounting/POS integrity, live runtime behavior and production restore.
